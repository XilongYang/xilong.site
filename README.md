# xilong.site

Source repository for [xilong.site](https://xilong.site), a statically generated personal blog,
built with [Kiln](https://github.com/xilongyang/kiln).

## Highlights

- Markdown article sources under `src/`
- Shared page templates under `template/`
- Front-end styles and scripts under `style/` and `scripts/`
- Everything else at the top level is generated by `kiln build`

## Building

```sh
nix run github:XilongYang/kiln          # build
nix run github:XilongYang/kiln -- clean # remove what the build generated
```

`kiln-config.json` says what goes where. The build is incremental — unchanged posts,
pages, and font subsets are skipped via `.cache/`.

## Repository Layout

```text
.
├─ src/                 # Markdown sources with front matter
├─ template/            # HTML templates and components
├─ style/               # CSS assets
├─ scripts/             # Front-end scripts
├─ res/                 # Static resources (fonts, images, third-party libs)
├─ kiln-config.json     # Build configuration
│
│  # generated by kiln build:
├─ post/                # Published post pages
├─ fonts-subset/        # Fonts subset to the characters the site uses
├─ index.html           # Homepage
├─ 404.html             # Not-found page
├─ atom.xml             # Atom feed
└─ searchdb.json        # Search database
```

## Post Source Format

Each post in `src/` starts with front matter:

```md
---
title: Your Post Title
author: Your Name
date: 2026-03-25
---

Abstract paragraph(s)...

<!--more-->

## First Section
Main content...
```

Date format: `YYYY-MM-DD`. Everything above the `<!--more-->` marker is the post's
abstract — shown on its own page and carried in the feed.
